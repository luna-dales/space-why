
# Thrust Vector Control

This section documents the development of the Space Why? thrust-vector-control system.

The project explores the mechanical, electronic, software, and control-system requirements for actively controlling a rocket's thrust direction.

## Project Areas

### Design

System requirements, design decisions, gimbal geometry, actuator selection, and control-system architecture.

### CAD

3D models and printable components for the thrust-vectoring mechanism and associated test equipment.

### Test Stand

Development of the static-fire test stand used to support and evaluate the two-axis thrust-vector-control system.

### Firmware

Software for sensor acquisition, attitude estimation, servo control, and closed-loop thrust-vector control.

### Testing

Mechanical testing, servo testing, sensor testing, gimbal testing, static-fire testing, and control-system evaluation.

### Data

Recorded test data used to evaluate system behavior and compare experimental results with predicted performance.

## Development Progression

The project is being developed iteratively:

1. Design and construct the mechanical TVC system.
2. Build and validate the static-fire test stand.
3. Characterize sensors and actuators.
4. Perform uncontrolled static-fire testing and collect baseline data.
5. Develop attitude estimation and filtering.
6. Implement closed-loop control.
7. Tune and evaluate the controller using experimental data.

## Status

Active development.
