
# Flying Blind

Flying Blind is the avionics and flight-computer portion of Space Why?

The project explores the design, construction, programming, testing, and flight evaluation of a custom rocket flight computer.

## Project Areas

### Hardware

Development of the flight computer from early prototypes through custom PCB designs, including component selection, power systems, sensors, data storage, and recovery-system interfaces.

### Firmware

Teensy-based flight software for sensor acquisition, data logging, altitude and motion estimation, flight-state detection, recovery-system control, and future thrust-vector-control integration.

### Testing

Bench testing, sensor testing, hardware validation, ground testing, and flight testing.

### Flight Data

Collection and analysis of recorded sensor and flight data, including comparison with simulations and predicted performance.

### Accessibility

Development of ways to make aerospace telemetry and engineering data more accessible, including low-vision-friendly visualization, redundant non-color cues, accessible data tables, and audio or sonification techniques.

## Current Development

Current development uses a Teensy 4.1 flight computer with onboard microSD storage and sensors including the MS5611 barometric pressure sensor and GY-521/MPU6050 inertial measurement unit.
